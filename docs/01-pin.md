# #1 暗証番号ロックを作ろう

0〜9のボタンを押して4桁の暗証番号（PIN）を入力し、正しいコードかどうかを判定するロック画面を作ろう。`#2 電卓をつくろう`では「ボタンを押すたびに数字が表示の末尾につながっていく」処理と、四則演算や小数点の処理を同時に組み立てる必要があります。ここではその前半部分（数字ボタン→文字列への連結）だけを、演算子や小数点を考えずに練習します。

### upstreamの更新を取り込む

`docs/setup.md`の手順で`gh repo fork jamashita/dango --clone`を使ってcloneした場合、コピー元の`jamashita/dango`を指す`upstream`というリモートが自動的に設定されています。サンプルが更新されているのでそれを取得しましょう。

```
git fetch upstream
git merge upstream/main
```

(補足) `git remote -v`を実行して`upstream`が表示されない場合は、以下を実行してから上のコマンドを試してください。

```
git remote add upstream git@github.com:jamashita/dango.git
```

その後、使用しているソフトウェアを最新化する

```
pnpm install
```

## 要件

1. `0〜9`のボタンを押すと、入力中のコードの末尾に1桁ずつ追加されること
2. コードは4桁までしか入力できないこと（4桁たまったらそれ以上ボタンを押しても増えないこと）
3. 「1文字削除」ボタンで、入力中のコードの最後の1桁を消せること
4. 「クリア」ボタンで、入力中のコードを空にできること
5. 4桁入力し終わったら、あらかじめコードの中に決めておいた正解（例: `'1234'`）と一致するかを自動的に判定し、「正解」または「不正解」を表示すること
6. (できれば) 入力中のコードをそのまま数字で表示せず、`●●●●`のように隠して表示すること

## 注意するところ

- 数字ボタンを押すたびに入力中の文字列の末尾に数字をつなげていく書き方は`src/components/samples/Counter.tsx`にサンプルがあります（`#2 電卓をつくろう`でも同じ考え方を使います）。読んで参考にするのはOKですが、トップページ(`/`)にそのまま表示されているファイルなので直接編集しないでください。「4桁で止める」「1文字消す」「正解判定する」はこのサンプルには入っていないので、要件を見ながら自分で実装してください
- 4桁を超えて入力させないためには、今の桁数（`文字列.length`）を数字を追加する前にチェックします
- 1文字削除は`文字列.slice(0, -1)`で「最後の1文字を除いた文字列」が作れます
- 正解判定は`===`で文字列同士を比較します。「入力されたコードが正解かどうか」を`boolean`型で返す関数を書いてみましょう
- 要件6（隠して表示）の書き方は`src/components/samples/MaskedCode.tsx`にサンプルがあります。読んで参考にするのはOKですが、こちらもトップページ(`/`)にそのまま表示されているファイルなので直接編集しないでください。「4桁で止める」「1文字消す」「正解判定する」はこのサンプルにも入っていません

## 考えなくていいこと

- 正解のコードをユーザーが自由に設定する機能は不要です。コードの中に固定の正解（例: `const CORRECT_CODE = '1234';`）を書いてしまって構いません
- 不正解が続いたときにロックする、といったセキュリティ的な機能は不要です

## 学習の意図

### `string`型を理解する

`number`型（数値）だけでなく、文字（`string`型）も扱えるようになります。`string`型は文字をsingle quote`'`かdouble quote`"`かbacktick`` ` ``で囲む必要があります。

```typescript=
const code: string = '1234';
```

### 文字列を連結する

`string`型同士は`+`で連結できます。

```typescript=
'12' + '3' // '123'
```

これを使うと、ボタンを押すたびに入力中のコードへ数字を1桁ずつ追加していけます。

```typescript=
const onDigit = (digit: string): void => {
  setCode(code + digit);
};
```

### 文字数を数える・切り詰める

文字列の長さは`.length`で数えられます。「4桁を超えたら追加しない」は、`if`と組み合わせれば実現できます。

```typescript=
if (code.length >= 4) {
  return;
}
```

「最後の1文字を消す」には`.slice(0, -1)`が使えます。`slice`は文字列の一部を切り出すメソッドで、`slice(0, -1)`は「最初から、最後の1文字を除いたところまで」を意味します。

```typescript=
'1234'.slice(0, -1) // '123'
```

### `boolean`型と`===`での比較を理解する

`boolean`型は`true`（はい）・`false`（いいえ）の2値だけを持つ型です。`===`は左右が等しいかどうかを`boolean`型で返す演算子で、`if`の条件にそのまま使えます。

```typescript=
const isCorrect: boolean = code === '1234';
```

### 値を返す関数を書く

`#0 カウンターを作ろう`で登場した関数は、`(): void`のようにすべて「値を返さない」関数でした。今回は「入力されたコードが正解かどうか」を`boolean`型の値として返す関数を書いてみましょう。`void`の代わりに戻り値の型（ここでは`boolean`）を書き、`return`で値を返します。

```typescript=
const isCorrectCode = (input: string): boolean => {
  return input === '1234';
};
```
